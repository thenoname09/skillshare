# SkillShare

SkillShare is an online learning platform where users can explore courses, create accounts, log in securely, and manage their personal profiles. The project is built with Next.js 15, Better Auth, MongoDB, and HeroUI for a modern and responsive user experience.

---

##  Live URL

🔗 https://skillshare-umber.vercel.app/

---

## 🎯 Project Purpose

The purpose of SkillShare is to provide a simple and modern learning platform where users can:

- Register and log into their accounts
- Access protected profile pages
- Explore available courses
- Authenticate securely using email/password or Google login
- Experience a responsive UI across all devices

---

## ✨ Key Features

- Authentication with Better Auth
-  Google Sign-In Integration
-  Protected Profile Route
-  Fully Responsive Navbar & Layout
-  Modern UI with HeroUI
-  Fast App Router Architecture with Next.js
-  MongoDB Database Integration
-  Middleware Route Protection
-  Password Validation & Error Handling
-  Real-time Session Refresh after Login/Register
